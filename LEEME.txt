¿QUÉ ES?
--------
Plataforma de detección y clasificación de microplásticos
(PET, PP y LDPE) por fluorescencia Nile Red bajo luz UV (254 nm)
e inteligencia artificial (YOLO v8 / v11).

INSTALACIÓN (PRIMERA VEZ)
-------------------------
1. Instala Python 3.11.x (NO 3.12+) desde
   https://www.python.org/downloads/release/python-3119/
   Marca "Add Python to PATH" y "tcl/tk and IDLE".

2. (Opcional, si tienes GPU NVIDIA) instala los drivers actualizados.

3. Doble clic en  SETUP.bat
   - Te PREGUNTA DÓNDE INSTALAR (ENTER = aquí mismo, o escribe otra carpeta)
   - Crea el entorno virtual .venv
   - Detecta GPU automáticamente
   - Instala PyTorch + ultralytics + PySide6 (5-15 min la 1ª vez)
   - Te ofrece crear un acceso directo en el Escritorio
   - Al terminar te dice CÓMO INICIARLO

   NOTA: los modelos entrenados (.pt) NO vienen en la descarga de GitHub
   por su tamaño. Copia tu archivo .pt dentro de la carpeta  models\
   para usar el Detector y el Visor.

ACTUALIZAR (TRAER LO NUEVO DE GITHUB)
-------------------------------------
Doble clic en  actualizar.bat
  - Mira si hay una version nueva en GitHub y la descarga.
  - Reemplaza solo el codigo del programa.
  - CONSERVA tu .venv, tus modelos models\*.pt, tus runs\ y datos.
  - No necesita Git, solo internet.

USO DIARIO
----------
Doble clic en el acceso directo "Poly-X" del Escritorio
(o en  iniciar_polyx.bat).
Se abre el menú principal con 4 módulos:

   🔬 Detector     · Analiza imágenes con un modelo .pt entrenado
                     y genera reporte HTML tipo paper.
   🎯 Entrenador   · Entrena modelos YOLO v8/v11 con curvas en vivo.
   🏷  Etiquetador · Anota imágenes en formato YOLO con
                     pre-anotación automática.
   📐 Visor        · Inspección + calibración interactiva μm/píxel.

FLUJO RÁPIDO (usar modelo ya entrenado)
---------------------------------------
1. Abre el Detector desde el launcher.
2. Pestaña "Modelos" → "Usar bestdetectormedium.pt" (carga rápida).
3. Pestaña "Imágenes" → selecciona tu carpeta.
4. Pestaña "Parámetros" → ajusta μm/píxel del microscopio.
5. Pestaña "Ejecutar" → ▶ Iniciar detección.
6. Pestaña "Reporte" → 📄 Generar reporte HTML  o  📑 Exportar a PDF
   (el reporte incluye la comparación Predicción vs Ground Truth lado a
   lado; todas las imágenes van embebidas, no se rompen al enviarlo).

ESTRUCTURA DE CARPETAS
----------------------
  polyx/              Código fuente (launcher, detector, ...)
  models/             Pesos .pt entrenados
  runs/               Resultados de cada corrida (timestamp)
  data/               Datasets YOLO (images/ + labels/)
  legacy/             Versiones anteriores del código (referencia)
  manual_screenshots/ Capturas usadas por el manual
  Manual_PolyX.html   Manual de usuario completo (abrir en navegador)
  SETUP.bat           Instalación
  iniciar_polyx.bat   Lanzador

REGENERAR EL MANUAL CON LA UI ACTUAL
------------------------------------
.venv\Scripts\python.exe generar_manual.py --solo launcher
.venv\Scripts\python.exe generar_manual.py --solo detector
.venv\Scripts\python.exe generar_manual.py            (todos)

PROBLEMAS COMUNES
-----------------
• "No module named tkinter"  →  reinstala Python marcando tcl/tk.
• "CUDA not available"       →  no es error, solo CPU es más lento.
• Detector no detecta nada   →  baja confianza a 0.10 en Parámetros.
• OOM en entrenamiento       →  baja batch a 4 o 2, e imgsz a 640.
